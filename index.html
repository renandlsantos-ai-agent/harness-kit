Ready-made Harness Kit for Claude Code and Codex

The model is not enough. Coding agents need a system around them. This kit will bundle four pieces into one repo template you can drop into a project.

  • Handbrake: permission rules and a stop switch before risky commands.
  • Loop breaker: stops runs that repeat the same failing step.
  • Project memory: context the agent keeps between sessions.
  • Proof of work: the agent must run checks before it says "done".
